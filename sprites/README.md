# sprites/

PokeHex doesn't ship any Pokemon artwork -- it's copyrighted by Nintendo/Game
Freak/Creatures Inc, and this repo is public.

If you want sprites in the GUI's preview panel, drop your own legally-obtained
image files here, named by national dex number:

```
sprites/6.png     # Charizard
sprites/25.png    # Pikachu
```

Supported formats: `.png`, `.jpg`, `.jpeg`, `.gif`.

Everything in this folder except this README is gitignored, so nothing you
add here will get committed or pushed to your public GitHub repo.
